BIRTHDAY BESTIE WEBSITE
========================

1. Unzip the folder.
2. Put your real photos inside the "images" folder.
3. Rename them:
   photo1.jpg
   photo2.jpg
   photo3.jpg
   photo4.jpg
   photo5.jpg
   photo6.jpg
   hero.jpg (optional; if missing, photo1.jpg is used)
4. Open index.html in a browser.
5. Password:
   24/09/2007
   (24-09-2007 and 24092007 also work)

IMPORTANT:
This is a front-end password lock. It is perfect for a birthday surprise website, but it is NOT strong security because the password is stored in the browser code. For a private surprise, do not put sensitive information here.

You can edit the letter in letter.html and change the memory text in memories.html.
